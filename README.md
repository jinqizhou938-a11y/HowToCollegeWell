## 这是什么

一本条目化的大学指南。**438 条**，18 章，从报到第一天写到毕业第一年。

和常见的"大学攻略"不一样的地方只有一条：**每条都写清依据**——法律给条号，政策给文名和文号，数据给报告名，文献给作者年份。查不到一手依据的，老实标成 C 级并写明"以本校文件为准"，不硬凑权威。

每条长这样：

| 这一栏 | 回答什么 |
| --- | --- |
| **成本** | 花掉什么：钱、时间、毅力 |
| **说人话** | 把政策和数字翻成日常说法。**只看这一行也能拿主意** |
| **收益** | 落到具体条文、具体数字或具体机制 |
| **证据等级** | A / B / C，见[下文](#证据分级) |
| **来源** | 指向原文，可自己核 |
| **备注** | 怎么判断、怎么执行、坑在哪、各校差异在哪 |

**不用全做。** 这是按性价比排好的备选单，不是任务清单——挑走一两条就算数。

## 怎么读

- **不用全做**：这是按性价比排好的备选单，不是任务清单。挑走一两条就算数，剩下的放着，需要时再回来查。
- **条目按性价比排，不按类别排**：每节内的条目从"成本低、收益大"往下排，所以第 1 条通常是最值得先做的。
- **每条长这样**（正式条目原文）：

```markdown
### 10. 助学金：平均每生每年 3700 元，按困难程度分 2 到 3 档
<!-- 成本标签: 钱=0 时间=中 毅力=是 收益=大 口径=金钱 -->
- 成本：不花钱，但要按学校要求提交材料并通过班级或年级评议。
- 说人话：国家助学金是"发给困难学生、不需要还"的钱。……（正文更详细）
- 收益：本文引政策原文、金额区间与分档规则。
- 证据等级：A
- 来源：财政部、教育部相关通知，链接到原文。
- 备注：各校差异。以本校学生资助管理中心当年通知为准。
```

- **"说人话"那一行就够拿主意**：它把"收益"栏里的政策原文和数字翻成日常说法。只看这一行也能做决定；想自己核对就看"收益"栏，再顺着"来源"栏点进原文。
- **按条件挑**：打开 [在线检索页](index.html)，可以按关键词、章节、证据等级筛选，也可以按"花不花钱、花不花时间、要不要毅力、换回什么"筛，几个条件能叠着用。页面上的内容直接取自 `book/` 目录的正文，正文一改，重新跑一次脚本页面就跟着改。
- **想按顺序读**：从每节前几条开始看就行。
- **来源都写在"来源"栏里，且指向原文**：法律引全国人大常委会公布的法律文本（带条号），政策引部委文件（带文名、文号、链接），数据引官方统计或权威机构报告，研究方法引具体文献（作者＋年份＋标题／期刊）。查不到一手依据的，会明写"属通行做法"并标 C 级——不写"某研究认为"这种没有指向的来源。
- **证据等级低的条目也要看**：本书有相当一部分条目是"通行做法"（C 级），因为中国高校的选课、保研、评奖规则各校差别很大，不存在全国统一的数字。这类条目给出的是判断方法和该问的问题，具体标准必须去查本校文件。标 C 不代表它没用，只代表它没有一份全国统一的原文做依据。

## 四种资源

这本书想帮你多留住的是四样东西，对应检索页上的四个"换回什么"：

- **成绩与学位**：绩点、排名、毕业学分、学位证。大多数门槛（保研、评奖、留学、部分岗位）都是用它换算的。
- **时间与精力**：活着的时间不花在没有回报的事上，每天的注意力和体力少被白白耗掉。睡眠和注意力是四年里最不可逆的资源。
- **金钱**：少花冤枉钱，把该领的资助领到手，不因为一次分期或一次骗局赔掉几年的生活费。
- **选择权**：不因为不知道一条规则，把自己的路走窄了——包括学籍、档案、应届生身份，也包括不作弊、不代写、不出租银行卡这些法律红线。

**一条件议的好处落在谁身上，是分档的。** 按"这份好处将来有多大可能回到你自己身上"从高到低：① **你自己**；② **同住的室友、家人、朋友**（安全与急救类条目多落在这里，因为你就住在他们旁边）；③ **同学与校友**（互惠关系）；④ **陌生人**。不同档不合并计算。

## 证据分级

每条建议都标注证据等级：

| 等级 | 含义 |
| --- | --- |
| A | 引到了法律条文（带条号）、国家部委文件（带文号）、官方统计数据或具名研究的原文，能说出具体数字或具体条款 |
| B | 有官方文件、官方机构数据或具名研究支撑，但具体数值／执行标准由地方或学校自定，说不出一份全国统一的原文 |
| C | 通行做法或编者自己的判断，没有直接的文件依据（会明写"属通行做法"或"本书作者判断"） |

全书 **438 条**中 A 级 **129 条**、B 级 **171 条**、C 级 **138 条**。**A 级只说明"有原文可核"，不说明这条一定适合你**——比如国家助学贷款的额度是全国统一的（A 级），但你该不该贷、贷多少，要按自己的情况定。有地区差异或各校差异的条目，在"备注"栏里写明"地区差异"或"各校差异"，检索页上会打一个"看备注"的标记。

**引用来源以原始文件为准**：法律引全国人大常委会公布的法律文本，政策引中国政府网、教育部、人社部、国家医保局、财政部、卫健委等部门的原文，数据引国家统计局、教育部或权威机构报告。不引二手转述。本书写作时间为 2026 年 10 月，政策类内容会更新，请以你看到时的最新文件为准。

## 性价比档

证据等级只回答"这个依据可不可信"，不回答"这件事值不值得做"。所以本书按两个维度给了性价比档：

| 维度 | 取值 | 怎么定的 |
| --- | --- | --- |
| 换回什么 | 成绩／时间精力／金钱／选择权 | 看这条主要换回的是哪一类。**不同口径之间不做比较**，"多拿 6000 元奖学金"和"少熬 30 个夜"不在一把尺子上 |
| 收益量级 | 大／中／小 | 尽量照着条目自己的"收益"栏套：换成绩看它是否跨过某个门槛（保研线、评奖线、毕业线）；换钱看金额（万元级为大，数百到数千为中，几十元为小）；换选择权看后果（影响学位或涉刑为大，影响评奖或资格为中，只影响一次体验为小）；换时间精力看省下多少（每天省出小时级为大，每周小时级为中，只省一次的为小） |
| 三项成本 | 钱／时间／毅力 | 分别标 0／低／中／高、少／中／多、是／否 |
| 性价比 | 极高／高／一般 | 好处大、三项成本又全是零＝极高；好处大、成本不高，或好处中等、成本为零＝高；剩下的＝一般 |

全书 438 条的分布：

| 维度 | 分布 |
| --- | --- |
| 换回什么 | 选择权 174 · 金钱 108 · 时间精力 89 · 成绩 67 |
| 收益量级 | 中 232 · 大 183 · 小 23 |
| 不花钱（钱＝0） | 323 条 |
| 不花时间（时间＝少） | 313 条 |
| 不需要毅力（毅力＝否） | 115 条 |
| 三项成本全为零 | **87 条** |
| 收益"大"且成本不高 | **159 条** |

全书共引用 **71 个官方来源链接**（法律条文、部委文件、官方平台、机构报告与具名文献），按类别汇总在 [docs/一手来源清单.md](docs/一手来源清单.md)。

**这一档是编者自己的判断，按本书的标准它本身只算 C 级**，和证据等级是两回事：一条可以证据是 A 级、性价比却只算一般（助学贷款的利率是全国统一的，但它是一笔要还的债），也可以证据只有 C 级、性价比却极高（把行程发给室友）。想直接看最划算的那些，打开检索页把"不花钱 + 不花时间 + 不需要毅力 + 收益大"勾上，再按性价比排序。

## 读懂术语（术语表）

正文尽量用日常说法，但讲到政策和制度时免不了出现几个词。看不懂就查这张表。

<details>
<summary>展开 58 条术语（绩点、推免、三方协议、微专业、帮信罪、紧急止付、PEP、热射病……）</summary>

| 术语 | 意思 |
| --- | --- |
| 培养方案 | 也叫人才培养方案。写清楚你这个专业四年要修哪些课、每类课要多少学分、什么时候能毕业的官方文件，教务系统里能下载 |
| 学分 | 课程的计量单位，一般一门课 1 到 5 学分，与课时挂钩。修满规定学分才能毕业 |
| 必修／限选／任选 | 课程的三类：必修是必须修的；限选是在一组里挑几门；任选是随便挑（通识课多属此类）。三类各有最低学分要求，缺一类就毕不了业 |
| 实践环节 | 实习、社会实践、毕业设计、创新创业等非课堂学分，最容易漏算 |
| 教学大纲 | 一门课的正式说明书：教学目的、进度、考核方式、成绩构成（平时分与期末各占多少）、参考书。选课之前就该看它 |
| 绩点（GPA） | 把百分制成绩换算成 4.0 或 5.0 制后，按学分加权平均得到的数。同一门课在不同学校换算出来的绩点可能不同 |
| 加权平均分 | 每门课成绩乘以该课学分数再求平均。学分大的课影响更大 |
| 专业排名／年级排名 | 排名口径不同，同一个人的名次会差很多。保研、评奖用的口径由本校文件规定 |
| 补考／重修 | 课程不及格先补考，补考仍不及格要重修。教育部要求成绩单对补考、重修获得的成绩予以标注 |
| 清考 | 以前部分学校在毕业前给不及格学生安排的"兜底补考"。教育部已要求取消，不要指望它 |
| 刷分 | 为了提高绩点重修已通过的课程。学校是否允许取最高分、是否标注，各校规定不同 |
| 学业预警 | 学校对学分未修满或成绩过低的学生发出的提醒与干预，处理不及时可能走到退学 |
| 降转 | 转专业后降一级就读，用于补修转入专业低年级的基础课 |
| 辅修 | 修完另一专业的一组课程，拿辅修证书。一般要求不晚于第二学年起始报名 |
| 辅修学士学位 | 辅修但达到学位要求，在主修学位证书上标注（不单独发一张学位证）。必须跨专业大类，且主修学位拿不到就一并作废 |
| 双学士学位 | 高考招生时就确定的两个专业一起读，毕业时在证书上标注两个学位。在校生中途不能加入 |
| 第二学士学位 | 本科毕业后再读两年的全日制学历教育，按当年应届生身份派遣。招应届和近三年未就业的往届生 |

## 自己跑一份

```bash
cd tools
python build_index.py
```

`build_index.py` 会读 `book/` 目录下所有 Markdown，解析出条目、章节、成本标签，生成自包含的单文件检索页 `index.html`（数据内嵌，双击就能开，不用服务器也不用联网）。正文一改，重新跑一次脚本，页面跟着改。

## 体例说明

本书的写法是定型的，改任何一章都按同一套规矩来：

- **一条一议**：一个条目只讲一件事，标题里带具体数字或明确动作（"睡眠时间不足 7 小时的，该改的是起床时间"这种能直接照做的写法，而不是"重视睡眠"）。
- **六个字段固定**：成本 / 说人话 / 收益 / 证据等级 / 来源 / 备注。成本标签写在 HTML 注释里（`<!-- 成本标签: 钱=… 时间=… 毅力=… 收益=… 口径=… -->`），检索页靠它做筛选。
- **节内按性价比排序**：不是按类别、也不是按重要性，而是按"花的少、拿的多"排。
- **来源必须指向原文**：法律给条号，政策给文名和文号，数据给机构报告名，方法给作者年份。查不到一手依据的明写"属通行做法"并标 C，不用"某研究认为"这类模糊说法。
- **不写结论性口号**：能落到"怎么办、去哪查、问谁"的就落，落不到的宁可不写。

## 还需要你自己去查的部分

本书能做到的是把"该问哪些问题、去哪找答案"写清楚。以下几类内容**必须**以本校或本地文件为准，本书只能给方法：

- 学分构成、绩点算法、排名口径、转专业门槛、评奖评优细则（学生手册＋培养方案＋学院文件）
- 保研名额与推免办法（学院推免办法，每年公示）
- 获奖学金的加分条目与分值（学院综测办法）
- 医保个人缴费标准、报销比例、异地就医备案流程（参保地医保局文件）
- 体测项目与评分标准（学校体育部门通知）
- 社保缴纳基数、应届生落户条件、公积金贷款额度（就业地当年政策）
