# 自学资源清单

配合第 6 章（考证与技能）和第 7 章（AI 自学、工具与学习路径）使用。

**这份清单的用法**：不要从头读到尾，也不要收藏了事。正确的用法是——**手上有一件具体的事**（要学一门课、要写一篇论文、要学一个工具），然后来这里找对应那一行的入口，用完就走。

**三条原则**（比清单本身更重要）：

1. **先查国家级平台，再考虑付费课。** 国家出钱建的课程平台里，一流课程是免费的，而且很多就是你本校老师录的。这一条能替你省下几千元。
2. **优先用你已经在付钱的资源。** 学校图书馆的数据库、学校买的正版软件、校内大模型服务——这些学校已经付过费了，你不用等于白交学费。**去图书馆和信息中心官网各翻一次，四年只用翻两次。**
3. **官方文档永远第一手，且免费。** 学工具、学编程、学软件，先看官方文档，再看别人的教程。二手资料永远比官方慢一步，而且会漏掉边界条件。

> **时效说明**：本清单写作时间为 2026 年 10 月。平台功能、课程数量、网址都可能变动，以你看到时的官网为准。凡是地址可能变化或你不确定的，本文只写平台名称与主办单位，请自行搜索官网，不给你一个可能失效的链接。

## 三、文献与数据（写论文必用）

| 资源 | 说明 |
| --- | --- |
| **学校图书馆的数据库** | 知网、万方、维普、超星，以及外文数据库。**多数高校已购买，用校园网或学校 VPN 访问完全免费。** 四年没进过图书馆官网的人太多了 |
| **图书馆的"文献传递"服务** | 你要的那篇文献本校没订，可以申请从其他馆传递过来，通常免费或很低价。**卡在"找不到文献"时，先问图书馆员** |
| **国家哲学社会科学文献中心** | 哲学社会科学类文献的免费获取入口（主办：中国社会科学院） |
| **中国国家数字图书馆**<br><http://www.nlc.cn/> | 电子书、期刊、古籍、学位论文 |
| **arXiv**<br><https://arxiv.org/> | 物理、数学、计算机等领域的预印本，免费全文。**注意：预印本未经同行评审** |
| **OpenAlex / Semantic Scholar / Connected Papers** | 免费文献元数据与引用关系工具。查一篇文献的"上下游"很好用 |
| **国家统计局**<br><https://www.stats.gov.cn/> | 写论文、做报告需要的宏观数据，第一手来源 |
| **国际组织数据库** | 世界银行、联合国、OECD、世界卫生组织等，都有免费的数据与报告接口 |

**查文献的三个动作**：① 先用关键词在图书馆数据库检索，看有没有人写过同一主题（这决定你是否需要换题）；② 找到一篇好的，看它的参考文献列表往前追、看谁引用了它往后追；③ 引用之前，**一定要拿到原文**——不要引二手转述，也不要引没读过的文献。

## 四、AI 相关的学习资源

### 官方文档（第一手，永远优先）

各家大模型与工具官方都提供提示词指南、使用文档和示例。**它们的更新速度比任何二手教程都快**，而且免费。要学一个工具，先找它的官方文档里的 "guide" 或 "docs" 栏目。

### 课程

| 资源 | 适合 |
| --- | --- |
| 国家高等教育智慧教育平台上的 AI 相关课程 | 想系统学，且有中文授课、有学分认定可能 |
| 中国大学 MOOC / 学堂在线 | 同上，国内高校的 AI 导论、机器学习、Python 课程 |
| DeepLearning.AI 的短课程 | 想快速上手某个 AI 工具或概念 |
| Hugging Face 课程 | 想动手跑模型、做微调 |
| 《动手学深度学习》（d2l.ai） | 想系统学深度学习，边读边写代码 |
| CS50 与其 AI 方向课程 | 零基础补编程，作业体系完整 |

### 国家职业与证书

**人工智能训练师**：2020 年 2 月正式成为新职业并纳入国家职业分类目录；2021 年由人力资源社会保障部与工业和信息化部共同发布《人工智能训练师国家职业技能标准》，设**五级/初级工至一级/高级技师共五个等级**，包含数据标注员、人工智能算法测试员两个工种。据人社部门公开信息，全国已有**超过 20 个与人工智能相关的新职业**纳入国家职业分类目录。

**报考前必须做两件事**（详见第 6 章第 3、4 条）：① 查发证机构是否已在人社部门备案；② 去"技能人才评价证书全国联网查询"确认证书能查到。查不到，就当它是一张培训结业证明。

### 学 AI 的正确顺序

**先用起来，再学原理。** 多数人的顺序搞反了——先买一本《深度学习》啃三章，然后放弃。更有效的顺序是：

1. **第一周**：注册一个通用大模型，把你这周最耗时的一件事交给它做，记录它哪里行、哪里不行。
2. **第一个月**：把 AI 接进你的一个具体流程（读文献、学一门课、写代码、做表格），形成一套你自己的提示词。
3. **第二个月**：开始做验证训练——**凡它给出的法条、数字、参考文献，一律回原始来源核**，看看它错在哪、错得像不像。
4. **第三个月往后**：选一个方向往深走——数据处理与自动化、知识库与检索增强、或者本专业 + AI 的交叉点。

**详细的工具清单、学习路径与边界规则，见第 7 章。**

## 六、怎么自己找到"这清单里没有的东西"

上面的清单不可能覆盖所有需求。真正常用的方法是这四步（也就是第 6 章第 27 条讲的那套）：

1. **先确定"该学什么"，而不是"有什么课"。** 找目标课程的**官方大纲（syllabus）**或目标教材的**目录**，它会告诉你知识的边界和顺序。从"别人的推荐清单"开始，通常学到一半就散了。
2. **先找官方文档，再找教程。** 工具、软件、编程语言、平台规则——官方文档是第一手且免费，还带示例。
3. **找一个有反馈的练习场。** 没有反馈的学习等于没有学习（这是"刻意练习"最核心的一条）。题库、开源项目、真实数据集、竞赛、能挑错的老师或同伴，都算。
4. **做出一个可交付物。** 一份能跑的程序、一份分析报告、一个能用的表格模板、一次公开汇报。**有产物才算学会，证书不算。**

### 搜索技巧（能直接提升找资料效率）

- `site:` 限定站内搜索。例：`site:moe.gov.cn 转专业` 只在教育部网站里搜。
- `filetype:` 找特定格式。例：`filetype:pdf 数据结构 课件`。
- **用英文再搜一遍。** 同一个主题，英文资料的密度往往高一个量级。把中文术语换成英文关键词重搜，经常能直接找到更权威的来源。
- **加上"官方"或"gov.cn""edu.cn"。** 想找政策原文，直接搜"关键词 + 部委名"。
- **查时间和版本。** 找到的资料先看日期——政策类、工具类资料超过两年的先存疑。

## 七、别做的事

- **不要收藏了当学过。** 收藏夹是"我以为我会看"的坟场。看到有用的，当天用一次。
- **不要一上来就报班。** 先确认"官方文档里有没有"、"国家平台里有没有"、"学校图书馆里有没有"，三处都空再考虑付费。
- **不要为了"看起来很努力"而买课。** 判断标准只有一个：**这门课有没有一个具体的交付物**。没有，就不买。
- **不要只学工具不学判断。** 工具每半年换一批，判断力不会。第 7 章的第 1 条和第 34 条都在讲这件事。
